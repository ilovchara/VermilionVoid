> 新建文章时，frontmatter 只有 `title` 和 `published` 是硬性必填，其余字段都有默认值。规则定义在 `src/content.config.ts` 的 `posts` 集合 schema 中。

## 必填字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | 字符串 | 文章标题，显示在文章页、列表页和 RSS |
| `published` | 日期 | 发布日期，决定排序和归档。**裸日期不加引号**，如 `2026-11-16` |

## 常用选填字段

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `description` | 字符串 | `""` | 摘要，显示在列表页；留空则自动截取正文前 140 字 |
| `category` | 字符串 | `""` | 分类名，决定侧边栏分组；留空显示「未分类」 |
| `tags` | 字符串数组 | `[]` | 标签，可写多个 |
| `image` | 字符串 | `""` | 封面图路径，如 `/images/cover.png` |
| `draft` | 布尔 | `false` | `true` 为草稿：开发模式可见，生产构建不发布 |
| `pinned` | 布尔 | `false` | `true` 为置顶，排在列表最前 |
| `updated` | 日期 | — | 更新日期，同样用裸日期 |

## 文章保护与声明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `encrypted` | 布尔 | `true` 启用密码保护 |
| `password` | 字符串 | 访问密码，仅在 `encrypted: true` 时有效。**仓库公开则密码和正文都会泄露** |
| `disclaimer` | 字符串或数组 | 文首免责声明，可选值见 `src/data/disclaimers.ts`，目前有 `暴论`、`免责声明`、`过时内容`，写错的值会被忽略 |

## 不用手写的字段

`prevTitle`、`prevSlug`、`nextTitle`、`nextSlug` 由 `src/lib/posts.ts` 按发布日期自动生成上下篇导航，frontmatter 里不需要填。`lang` 是语言标记，一般也用不到。

## 可直接复制的模板

```markdown
---
title: 文章标题
published: 2026-11-16
description: "一句话摘要"
category: 技术笔记
tags:
  - 标签一
  - 标签二
image: ""
draft: false
pinned: false
---

正文从这里开始。
```

## 新建文章的方式

项目没有内置 `pnpm new` 之类的建文命令。手动在 `src/content/posts/` 下新建 `.md` 或 `.mdx` 文件即可，支持任意层级子目录，例如 `src/content/posts/2026/11-技术笔记/我的新文章.md`。目录结构只影响文件归属，URL 由文件路径生成。

写完后运行 `pnpm dev` 预览，`pnpm build` 构建（含 Pagefind 搜索索引）。

## 写作格式约定

- 标题简短有力，中文全角标点。
- 中文与英文、数字之间留一个半角空格，如「在 Astro 中」。
- 段落保持简短，一段一个主题，用二级、三级标题分解内容。
- 列表用于并列项，有序列表仅用于步骤。
- 关键术语用**加粗**，不要用代码块来强调。
- 日期字段不加引号，否则 `z.date()` 校验失败。
